# 网络架构说明

## 拓扑概述

```
                    ┌─────────┐
                    │ Internet │
                    └────┬────┘
                         │ 203.0.113.0/30
                    ┌────┴────┐
                    │ pfSense │ (防火墙/路由器)
                    │  WAN: 203.0.113.2
                    │  LAN: 192.168.1.1
                    └────┬────┘
                         │ 192.168.1.0/24
              ┌──────────┼──────────┐
              │          │          │
        ┌─────┴─────┐   │   ┌──────┴──────┐
        │  Kali     │   │   │   Snort IDS │
        │ (攻击机)   │   │   │  192.168.1.3│
        │ 192.168.1.100  │   └─────────────┘
        └───────────┘   │
                   ┌────┴────┐
                   │  Switch │
                   └────┬────┘
                        │
              ┌─────────┼─────────┐
              │         │         │
        ┌─────┴────┐  ┌─┴──────┐  ┌┴──────────┐
        │ Target-1 │  │Target-2│  │  Target-3  │
        │ Web Srv  │  │ FTP Srv│  │ DNS Srv    │
        │ .10      │  │ .20    │  │ .30        │
        └──────────┘  └────────┘  └────────────┘
```

## IP 地址规划

| 设备 | IP 地址 | 角色 | 操作系统 |
|------|---------|------|----------|
| pfSense WAN | 203.0.113.2/30 | 防火墙外口 | FreeBSD |
| pfSense LAN | 192.168.1.1/24 | 防火墙内口/网关 | FreeBSD |
| Kali | 192.168.1.100/24 | 攻击机 | Kali Linux |
| Snort | 192.168.1.3/24 | 入侵检测 | Ubuntu |
| Target-1 | 192.168.1.10/24 | Web 靶机（Apache） | Ubuntu |
| Target-2 | 192.168.1.20/24 | FTP 靶机（vsftpd） | Ubuntu |
| Target-3 | 192.168.1.30/24 | DNS 靶机（BIND9） | Ubuntu |

## 网络服务

| 靶机 | 开放端口 | 服务 | 用途 |
|------|----------|------|------|
| Target-1 | 80, 443 | Apache2 | Web 攻击实验 |
| Target-2 | 21, 22 | vsftpd, SSH | FTP 攻击实验 |
| Target-3 | 53 | BIND9 | DNS 劫持实验 |

## 安全隔离

- 所有实验在 EVE-NG 虚拟网络中进行
- pfSense WAN 口不连接真实互联网（使用模拟 ISP）
- 攻击流量不会泄露到生产网络
- 快照备份：实验前创建 VM 快照，结束后恢复
